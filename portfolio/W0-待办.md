## ② 建 GitHub 仓库并推送（40 分钟）

### 步骤

1. 打开 https://github.com/signup ，用邮箱注册（用户名建议 `liujianan` 或 `jliu-med`，别用花名）。
2. 右上角 **+ → New repository**
   - Repository name: `bid-deviation`
   - 选 **Private**（重要：仓库里有真实招标文件，先私有）
   - 不要勾 "Add a README"（本地已有）
3. 本机执行（把 `<你的用户名>` 换成实际用户名）：

```bash
cd C:/Users/Administrator/code/bid-deviation
git remote add origin https://github.com/<你的用户名>/bid-deviation.git
git branch -M main
git push -u origin main
```

4. 推送时会要密码 —— **GitHub 早已不支持密码**，要用 Personal Access Token：
   GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → 勾 `repo` → 复制生成的串，粘贴到密码位置。

### 什么时候可以改 Public

等下面三条都成立：① 招标文件/客户资料已移到仓库外；② 检测报告、授权书等 PDF 已删除；③ 你的照片、微信记录清单已清空。**在此之前一律 Private。** 面试时可以直接把仓库权限开给面试官看，比公开更安全。
